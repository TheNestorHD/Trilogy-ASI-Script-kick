# Catálogo de efectos — GTA San Andreas Chaos Mod

Este catálogo se generó desde el registro de efectos de la GUI de GTA Chaos Mod, fijado en el commit `688dccc2622ad85985d893bb683f0582f59d9b98` de `gta-chaos-mod/Trilogy-GUI-Tool`.

- Incluye **401 entradas**, contando variantes de vehículos que aparecen y destinos de teletransporte individuales.
- La columna **ID exacto del JSON** corresponde a la clave de `effect_durations.json`. **No la traduzcas ni la cambies.**
- La columna **Nombre gracioso personalizado (completar)** es para tus traducciones/nombres rioplatenses.
- Copiá el nombre elegido al campo `name` de ese mismo ID en `effect_durations.json`. Reiniciá la GUI para que cargue el cambio.
- Las descripciones son una **guía para localizar y entender los efectos**, no una traducción oficial: muchas salen del nombre/comentario del catálogo, y las más confusas tienen una referencia al código del efecto cuando pude contrastarlas. Conviene probar en el juego los efectos con nombres de meme antes de ponerles un nombre demasiado específico.
