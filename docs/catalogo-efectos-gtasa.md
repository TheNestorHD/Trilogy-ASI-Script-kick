# Catálogo de efectos — GTA San Andreas Chaos Mod

Este catálogo se generó desde el registro de efectos de la GUI de GTA Chaos Mod, versión fijada en el commit `688dccc2622ad85985d893bb683f0582f59d9b98` del repositorio `gta-chaos-mod/Trilogy-GUI-Tool`.

- Efectos registrados en el catálogo: **401** (incluye vehículos de aparición y destinos de teletransporte individuales).
- La columna **ID exacto del JSON** es la clave de `effect_durations.json`. **No la traduzcas ni la modifiques.**
- La columna **Nombre gracioso personalizado** es la que podés completar con tus nombres rioplatenses.
- Luego copiá el texto de tu nombre personalizado al campo `name` de ese ID en `effect_durations.json`.
- Los resúmenes marcados como **Revisar** corresponden a nombres de meme o efectos cuyo título no alcanza para afirmar la mecánica exacta. Dejé esa marca a propósito para no inventar.
- El JSON se carga al arrancar la GUI: reiniciá la GUI luego de editarlo.
